# 점검 안전 매뉴얼

모든 점검·교체 작업은 이 매뉴얼의 정지 절차와 작업 전 확인 사항을 먼저 수행한 뒤 시작한다.

## 6.1 점검 전 설비 정지 절차

**이상 징후**
- 해당 없음 (모든 점검 전 공통 절차)

**판단 기준 수치**
- 정지 후 회전부가 완전히 멈출 때까지 최소 5분 대기한다.
- 전원 차단 후 잔류 전압이 50 V 미만인지 테스터로 확인한다.

**점검 체크리스트**
1. 라인 담당자와 생산 관리자에게 정지 예정 시각을 알린다 (병목 설비는 사전 승인).
2. 설비를 정상 정지 순서로 멈춘다 (비상정지 버튼은 비상시에만 사용).
3. 주 전원 차단기를 내리고 잠금장치(LOTO)와 작업 표지를 건다.
4. 회전부가 완전히 멈췄는지 확인한다.
5. 잔류 전압을 측정해 50 V 미만인지 확인한다.
6. 재기동 시도로 실제 정지 상태를 검증한다 (기동 버튼을 눌러 움직이지 않는지 확인).

**교체 기준**
- 해당 없음. 잠금장치나 표지가 손상되었으면 사용하지 말고 교체한다.

## 6.2 압력·유체 계통 잔압 제거

**이상 징후**
- 밸브/펌프·배관 작업 전 공통 절차

**판단 기준 수치**
- 압력 게이지가 0 kPa(대기압)을 가리킬 때까지 배출한다.

**점검 체크리스트**
1. 6.1 정지 절차를 먼저 마친다.
2. 흡입·토출 밸브를 닫고 잠금 표지를 건다.
3. 드레인 밸브를 천천히 열어 잔압과 유체를 배출한다.
4. 압력 게이지가 0인지 확인한 뒤 작업을 시작한다.

**교체 기준**
- 드레인 밸브가 막혀 잔압이 빠지지 않으면 작업을 중단하고 보고한다.

## 6.3 작업 전 확인 사항

**이상 징후**
- 해당 없음 (모든 점검 전 공통 확인)

**판단 기준 수치**
- 2인 1조 작업을 원칙으로 한다.
- 작업 허가서 유효 시간(발행 후 8시간) 안에서만 작업한다.

**점검 체크리스트**
1. 작업 허가서와 점검 대상 설비 번호가 일치하는지 확인한다.
2. 보호구(안전화, 보안경, 절연 장갑)를 착용한다.
3. 필요한 교체 부품의 재고와 품번을 확인한다.
4. 해당 매뉴얼(모터/전원부, 구동부, 밸브/펌프, 베어링, 센서) 절차를 준비한다.
5. 최근 7일 정비 기록을 확인해 직전 교체 이력이 있는지 본다 (있으면 manual_sensor.md 5.1).

**교체 기준**
- 해당 없음.

## 6.4 작업 후 재가동 절차

**판단 기준 수치**
- 재가동 후 30분간 센서 값이 평소 대비 ±10% 안에 있는지 확인한다.

**점검 체크리스트**
1. 공구·부품이 설비 안에 남아 있지 않은지 확인한다.
2. 커버·가드를 원위치한다.
3. 잠금장치를 작업자 본인이 해제한다.
4. 라인 담당자에게 알리고 재가동한다.
5. 정비 기록(교체 부품, 시각, 작업자)을 남긴다.

**교체 기준**
- 해당 없음.

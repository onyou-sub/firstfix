# 센서·배선·설치 상태 점검 매뉴얼

부품을 교체한 직후에도 같은 이상(같은 센서 값 이탈, 같은 에러)이 계속되면 부품 자체보다 센서 고정·배선·설치 상태 문제일 가능성이 높다.
이 경우 같은 부품을 다시 교체하기 전에 이 매뉴얼의 절차를 먼저 수행한다.
센서별 기준값(1년 평균): 전압 170.8 V, 회전수 446.6 rpm, 압력 100.9 kPa, 진동 40.4 mm/s.

## 5.1 부품 교체 직후 같은 이상이 계속될 때 판단

**이상 징후**
- 최근 7일 안에 교체한 부품과 관련된 센서 값이 교체 전과 비슷하게 계속 벗어나 있다.
- 교체 후에도 같은 에러(overvoltage, low_rpm, torque, pressure, vibration)가 다시 기록된다.

**판단 기준 수치**
- 교체 후 24시간 평균이 교체 전 24시간 평균과 비교해 개선 폭이 3% 미만이면 센서·설치 문제를 우선 의심한다.
- 교체 후 24시간 안에 같은 에러가 1회 이상 다시 나면 센서·배선 점검 대상이다.
- 예: 모터/전원부 교체 후에도 전압 24시간 평균이 평소 대비 10% 이상 높고 overvoltage 에러가 다시 남.

**점검 체크리스트**
1. 정비 기록에서 교체 일시, 교체 부품, 작업자를 확인한다.
2. 교체 작업 중 분리했던 센서·커넥터 목록을 확인한다.
3. 아래 5.2~5.4 절차를 순서대로 수행한다.
4. 점검 결과를 정비 기록에 남기고, 같은 부품의 재교체는 점검 완료 후에만 결정한다.

**교체 기준**
- 센서·배선·설치 점검에서 문제가 없을 때만 부품 불량(초기 불량)으로 판단해 재교체한다.

## 5.2 센서 고정 상태 점검

**이상 징후**
- 진동·회전수 센서 값이 실제 소음·상태와 맞지 않게 튄다.

**판단 기준 수치**
- 센서 3시간 표준편차가 평소의 1.5배 이상이면 고정 불량을 의심한다.
- 휴대용 측정기 값과 센서 값 차이가 5% 이상이면 센서 이상으로 본다.

**점검 체크리스트**
1. 설비를 정지하고 전원을 차단한다 (manual_safety.md 6.1 절차).
2. 센서 마운트 볼트·자석 베이스의 풀림을 확인하고 규정 토크로 조인다.
3. 센서 부착면의 도장·이물·기름을 제거한다.
4. 교체 작업 때 센서 위치가 바뀌지 않았는지 표시선과 비교한다.

**교체 기준**
- 고정 후에도 측정기 값과 5% 이상 차이 나면 센서를 교체한다.

## 5.3 배선·커넥터 점검

**이상 징후**
- 값이 순간적으로 0이 되거나 최대값으로 튄다.
- 설비를 건드리면 값이 바뀐다.

**판단 기준 수치**
- 1시간 안에 값이 평소 대비 ±30% 이상 순간 변동이 3회 이상이면 배선 불량을 의심한다.

**점검 체크리스트**
1. 커넥터 체결(잠금 클립)과 핀 부식·휨을 확인한다.
2. 케이블 피복 손상, 꺾임, 동력선과의 근접 배선(노이즈)을 확인한다.
3. 실드 접지 상태를 확인한다.
4. 배선 도통 시험을 한다.

**교체 기준**
- 핀 손상·피복 손상이 있으면 커넥터·케이블을 교체한다.

## 5.4 설치·정렬 상태 점검

**이상 징후**
- 부품 교체 후 진동이나 토크 관련 값이 오히려 늘었다.

**판단 기준 수치**
- 교체 후 진동 24시간 평균이 평소 대비 10% 이상 높으면 설치·정렬 불량을 의심한다.

**점검 체크리스트**
1. 교체 부품의 축 정렬(얼라인먼트)을 측정한다.
2. 베이스·하우징 체결 토크를 확인한다.
3. 교체 부품의 품번이 설비 모델에 맞는지 확인한다.
4. 시운전 후 24시간 기록을 다시 확인한다.

**교체 기준**
- 정렬·체결을 바로잡은 뒤 24시간 평균이 평소 대비 ±5% 이내로 돌아오면 추가 교체는 하지 않는다.
